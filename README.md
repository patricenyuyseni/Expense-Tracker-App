 Expense Tracker 

A simple and responsive Expense Tracker Web App built with HTML, CSS, and JavaScript that allows users to track their income and expenses, view their balance, and manage transactions with persistent storage using the browser’s localStorage.

 Features
Add income and expense transactions
Automatically calculates:
Total balance
Total income
Total expenses
Delete transactions
Data persists after page refresh (localStorage)
Clean and responsive user interface
Beginner-friendly, no frameworks required
